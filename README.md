# Aethera® — Living Planet & Eco-Technological Intelligence

> *"Beyond silence, we build the eternal."*

A luxury, full-featured spatial web application built with **React**, **Vite**, **Tailwind CSS**, **TypeScript**, and **Interactive 3D WebGL / Canvas 2D**. Engineered for deep creative flow, spatial aesthetics, and zero-latency human interaction.

Designed & Engineered in Partnership with **[PaloSite Studio](https://palosite.com)** (`hello@palosite.com`).

---

## 🌿 Key Features

1. **Cinematic Looping Video Background Engine**
   - Seamless loop playback with `requestAnimationFrame` 0.5s fade-in/fade-out transitions and 100ms reset delay.
   - Minimal vignette blending so high-definition landscape video motion remains crystal-clear.

2. **60 FPS Interactive 3D Particle Canvas (`Nature3DCanvas`)**
   - 3D perspective projected botanical/pollen particles with dynamic Z-depth (-400 to 400).
   - Constellation line linking and smooth mouse parallax spring mechanics.

3. **3D Mouse Parallax Tilt System (`ThreeDCard`)**
   - Real-time 3D rotation (`perspective(1000px) rotateX(...) rotateY(...) scale3d(...)`) based on cursor position.
   - Specular light glare overlay that dynamically tracks cursor angle over portfolio cards, manifesto panels, and journal essays.

4. **3D Revolving Studio Radar Globe (`ReachUsSection`)**
   - 60 FPS continuous 3D latitude/longitude globe revolving on a 3D axis.
   - Real-time pulsing radar nodes for **Zürich**, **Tokyo**, **San Francisco**, and **Tashkent**.

5. **Organic Nature Design System**
   - **Deep Forest Green** (`#1E3A27`), **Warm Linen** (`#FDFBF7`), **Sage Slate** (`#5A6E5D`), and **Forest Ink** (`#1A2E20`).
   - Pure black (`#000000`) and heavy white fog overlays are completely eliminated in favor of warm, organic editorial aesthetics.

6. **Built-in Security & Code Protection (`SecurityWrapper`)**
   - Right-click context menu deterrence with toast notice.
   - Inspector hotkey blocker (`F12`, `Ctrl+Shift+I`, `Ctrl+Shift+J`, `Ctrl+U`, `Ctrl+S`).
   - Text & asset scraping prevention (`user-select: none`).

7. **Vercel Production Deployment Ready**
   - `vercel.json` configured with SPA rewrites and HTTP security headers (`Strict-Transport-Security`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`).

## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/Palonziy/nature.git
cd nature

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build production bundle
npm run build
```
